# 備品購入申請ワークフロー

架空の会社を想定した、備品購入の申請・承認を管理するJavaアプリケーションです。
職業訓練でJavaを学びながら、段階的に機能を追加しています。

## 概要

社員が備品の購入を申請し、上長が承認または差し戻しを行うワークフローを、
状態遷移として表現しています。不正な操作(例:下書きのまま承認する)は
例外で止める仕組みを入れています。

## 状態遷移

```
下書き → 申請中 → 承認済み → 完了
           ↓
         差し戻し → (修正して)申請中
```

## 実装済みの機能

- [x] 状態遷移(下書き→申請中→承認済み/差し戻し→完了)
- [x] 上長のみ承認・差し戻しができる権限チェック
- [x] 上長のみ完了にできる権限チェック
- [x] 自己承認・自己差し戻しの禁止
- [x] 不正な操作を例外で止める仕組み
- [x] 承認履歴の記録(申請・承認・差し戻し・完了)
- [x] コンソールのメニューから操作できる

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Main.java` | 動作確認用のメインクラス |
| `Request.java` | 申請クラス(状態遷移とチェックのルール) |
| `RequestStatus.java` | 申請の状態を表すenum |
| `Employee.java` | 社員クラス |
| `Role.java` | 役割(一般/上長)を表すenum |
| `ApprovalHistory.java` | 承認履歴クラス(操作した人・内容・日時を記録) |
| `Menu.java` | メニュー画面(こちらを実行して操作します) |

## 動かし方

1. このリポジトリをクローン(またはダウンロード)する
2. VS Codeで開く(Java拡張機能が必要)
3. `Menu.java` を実行する
4. 番号を入力して操作する(例:1で申請作成 → 2で提出 → 3で承認 → 5で完了)

## 作った理由

前職でWindchillのワークフローのエラーチェックや、設計書をもとにした改善案の検討を
していた経験から、ワークフローの状態管理を題材にしました。
※ 題材はすべて架空のもので、実際の会社のデータやルールは含みません。
